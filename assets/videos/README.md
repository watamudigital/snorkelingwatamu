# Juma ocean video

Upload the optimized H.264 MP4 video with this **exact filename** into this folder:

`juma-ocean-experience.mp4`

The website's "Il tuo mare, con Juma" section checks for
`/assets/videos/juma-ocean-experience.mp4`. Once this file is committed and
published by Vercel, the image automatically becomes a native HTML5 video,
playing muted and inline where the browser allows it, with visible controls.
With no video file, the existing Subira photo remains on screen.

To avoid storing oversized MOV files in GitHub, use the already prepared
web-optimized MP4 (around 3.9 MiB), not the 27 MB source MOV.
